# Security

## Reporting a vulnerability

Report security problems in `pyre` privately, through GitHub's private vulnerability reporting:
the **Report a vulnerability** button on the
[Security tab](https://github.com/pyre/pyre/security/advisories/new) of this repository. Please do
not open a public issue or pull request for them.

A useful report names the release or commit that is affected, describes how to reproduce the
problem, and what an attacker could do with it. The discussion, and any fix, happen on the
advisory the report opens, which stays private until the fix is released.

## Supported versions

Fixes are made on `main` and ship in the next release; earlier releases do not receive them.
